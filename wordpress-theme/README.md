# Pure Fitness Store — WooCommerce Theme

A modern, fully featured WooCommerce theme for WordPress, built for the Pure Fitness brand.

## Features

- **Modern design** — bold Oswald/Inter typography, dark sticky header, orange accent colour, card-based layouts with hover effects.
- **Full WooCommerce support** — product gallery zoom, lightbox and slider, styled shop grid, single product page, cart, checkout, my-account and reviews.
- **Live AJAX cart count** — the header cart badge updates instantly when products are added to the cart (no page reload).
- **Front page sections** — hero banner, "Shop by Category", "Featured Products", "On Sale Now" (with automatic discount-percentage badges) and "New Arrivals", each toggleable from the Customizer.
- **Customizer options** — announcement top bar, hero text/image/button, and homepage section toggles (Appearance → Customize).
- **Responsive** — off-canvas mobile menu with animated hamburger, fluid product grid from 4 columns down to 1.
- **Widget areas** — filterable shop sidebar plus 4 footer columns.
- **Accessible & translation-ready** — skip links, ARIA labels, keyboard-closable mobile menu, and all strings wrapped in the `pure-fitness-store` text domain.

## Installation

1. Copy the `pure-fitness-store` folder into `wp-content/themes/` of your WordPress install
   (or zip it and upload via **Appearance → Themes → Add New → Upload Theme**).
2. Install and activate the **WooCommerce** plugin (Plugins → Add New → search "WooCommerce").
3. Activate **Pure Fitness Store** under **Appearance → Themes**.
4. Run the WooCommerce setup wizard to create the Shop, Cart, Checkout and My Account pages.
5. Set a static front page (**Settings → Reading → Your homepage displays → A static page**) to enable the hero front page.
6. Customize the hero, top bar and homepage sections under **Appearance → Customize**.

## Requirements

- WordPress 6.0+
- PHP 7.4+
- WooCommerce 8.0+
